# Módulos DDM SNOC Windows

Esta pasta contém apenas módulos que ainda exigem arquivos locais no endpoint.

- ADDS: coletores mínimos de DCDiag e Repadmin.
- HYPERV: descoberta e métricas não cobertas integralmente por itens nativos.
- TOTVS: coleta legada mantida até substituição validada.
- VEEAM: coleta local mantida até migração validada para API.
- CORE: parâmetros comuns do produto.

MSSQL, PostgreSQL, MongoDB e IIS usam plugins ou templates nativos e não possuem scripts neste diretório.
