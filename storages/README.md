# Storages

## Dell PowerVault ME Series

Monitoramento nativo pelo Zabbix usando a API HTTPS das controladoras.

Diretório: [`dell-powervault-me`](./dell-powervault-me/)

## Dell PowerVault MD3200 / MD3200i

Monitoramento pelo Dell MDSM/SMcli. A coleta pesada roda fora do Zabbix e grava JSON em cache local; o Zabbix apenas lê os arquivos em milissegundos.

Diretório: [`dell-powervault-md3200`](./dell-powervault-md3200/)
