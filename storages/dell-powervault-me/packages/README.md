# Pacote PowerVault ME

O pacote contém o template final, o teste de API e toda a documentação desta solução.

Como arquivos binários não são enviados diretamente pela integração, o ZIP está versionado em partes Base64.

```bash
chmod +x build-package.sh
./build-package.sh
unzip -l powervault-me-monitoring-v1.1.0.zip
```
